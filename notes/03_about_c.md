# C 언어에 대하여

## 1. 변수
> 참고 코드: [03_01_variable.c]

- 메모리는 임의 접근 방식이라 각 칸에 주소가 있고, CPU는 이 주소로 데이터를 읽고 씀
- 변수는 메모리 공간에 사람이 읽기 쉬운 이름(x, y 등)을 붙인 것
    - 이름으로 값을 저장·변경할 수 있어 주소를 직접 다룰 필요가 없어짐
    - 실제로는 컴파일된 코드가 여전히 주소로 접근함
- declaration: 정수 하나를 담을 공간을 확보하고 x라는 이름을 붙임
- assignment: 그 공간에 값을 넣음
- 선언만 하고 값을 넣지 않으면 쓰레기 값이 들어 있을 수 있음

## 2. 자료형
- 변수가 어떤 종류의 데이터인지 미리 지정하는 것
- 필요한 이유
    1. 메모리의 값은 0과 1일 뿐이라, 같은 비트라도 정수인지 실수인지에 따라 해석과 연산 방법이 다름. 컴파일러에게 어떻게 다룰지 알려줌
    2. 자료형마다 필요한 메모리 크기가 달라 효율적으로 공간을 씀
