# C언어 시작

## 1. C언어 특징
1. 장점
    - 유닉스 운영체제를 만들기 위해 쓰인 언어라 효율성이 높고, 하드웨어 제어에 좋음
    - 프로그래머에게 많은 권한을 줌

2. 단점
    - 권한이 많기에 책임도 많음 (메모리 관리 등을 직접 해야 함)

## 2. C언어와 함수 
> 참고 코드: [02_01_exitcode.c](../ex/ch02/02_01_exitcode.c)
- 코드 수정 후에는 컴파일을 다시 해야 반영됨
- 료 코드는 화면에 따로 출력되지 않음. 터미널에서 보려면 실행 직후 `echo $?`
- C 프로그램이 실행되면 운영체제와 미리 약속된 이름인 main 함수를 찾아 그 안의 코드부터 실행

## 3. 컴파일러와 링커
- 컴파일러: 소스 코드를 기계어로 변환하는 것
- 과정: 소스 코드 작성-> .c 파일 하나당 오브젝트 코드(.o) 생성-> 링커가 오브젝트 코드들을 엮어 실행 파일로 만듦
    - 라이브러리(printf 등)와 start-up 코드는 링커가 찾아서 넣어줌

## 기타 
실행 파일 형식 (.exe vs .out)
- .exe는 윈도우 규칙. 윈도우는 확장자로 실행 파일을 판단-> 강의(Visual Studio)에서는 .exe 생성    
- 리눅스는 확장자를 보지 않음. 실행 권한(x)과 파일 형식(ELF)으로 판단-> 원래는 확장자 없이 만드는 게 일반적
    - 확인: `ls -l 파일.out` (권한에 x 있는지), `file 파일.out` (ELF 64-bit 등 형식 표시)
- 실행 파일 형식은 컴파일한 운영체제가 결정. 리눅스에서 이름을 .exe로 붙여도 내용은 ELF라 윈도우에서 실행 안 됨
- .out을 쓰는 이유
    - .gitignore C 템플릿의 `*.out` 규칙으로 실행 파일을 커밋에서 자동 제외하려고
    - 관례: gcc에서 -o 없이 컴파일하면 기본 이름이 `a.out` (옛 유닉스의 assembler output)
