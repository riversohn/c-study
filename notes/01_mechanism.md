# 컴퓨터 작동원리

## 1. 메모리의 기본 구조
- Random Access 방식: 임의 접근 방식, 데이터의 물리적 위치 상관없이 주소만 알면 어떤 위치든 즉시 접근 가능
- cpu와 메모리 사이에는 세가지의 버스가 존재
- address, data, control 세가지를 분리해서 데이터 주고 받음

## 2. CPU의 기본 구조
- 프로그램의 시작 과정: 프로그램은 보조기억장치에 저장-> 실행 시 운영체제에게 요청-> 운영체제는 보조기억장치에서 메모리로 프로그램 복사-> 메모리와 cpu의 처리
- 제어장치, ALU, 레지스터로 구성

## 3. CPU 일하는 방법
- cpu는 주소를 통하여서 메모리에서 정보를 가져오고 저장함
- 프로그램 실행 과정
- PC(program counter, 다음에 실행할 명령어의 주소)
1. Fetch
    - PC의 주소-> 메모리 주소 레지스터(MAR)
    - 그 주소의 값-> 메모리 데이터 레지스터(MDR)
    - 인출 단계에서 읽은 값이므로 명령어 레지스터(IR)로 이동
    - PC+ 1
2. Decode
    - IR의 명령어를 제어장치가 해석
3. Execute
    - 명령어가 가리키는 주소-> MAR-> 그 주소의 값-> MDR
    - 명령어에 따라 어큐뮬레이터로 옮기거나 ALU에서 연산, 연산 결과는 어큐뮬레이터에 저장
    - 저장 명령어면 어큐뮬레이터 값-> MDR-> MAR의 주소에 기록
4. 1번 부터 반복
- 메모리의 값에는 명령어/데이터 표시가 없음. 어느 단계에서 읽었는지가 쓰임새를 결정
- 변수는 단지 메모리 주소에 붙인 이름, 포인터는 즈 주소 자체를 다루는 것

## 기타
- random access의 의미: 무작위 보다는 임의의 의미가 강함, 옛날 저장장치인 자기 테이프는 순차 접근 방식이라 그것의 반대되는 개념으로 이름을 지으니 이렇게 지어진 것 같음, 순서에 얽매이지 않고 임의로 접근할 수 있다고 해서
